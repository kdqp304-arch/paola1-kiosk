# PAOLA-1 터치 화면 (iPad 설치형 웹앱)

- 주소: https://kdqp304-arch.github.io/paola1-kiosk/
- 현재 버전: 22 (빌드 55085315) · 2026-10-12
- iPad 사파리에서 주소를 열고 공유 → "홈 화면에 추가"를 누르면 아이콘이 생기고, 앱처럼 전체 화면으로 열려요.
- 처음 한 번 인터넷이 켜진 상태에서 열어두면, 그다음부터는 인터넷 없이도 열려요.
- 사용법: 화면을 꾹 눌러 위의 막대 3개를 채우면(2초) 손을 떼도 D-카운트(1초) 후 11.1 급여 화면이 나와요. 10초 뒤 처음 화면으로 돌아가요.
- 날짜: 10/23 전에는 D-9, 10/23부터는 실제 날짜를 따라가요.
- 미리보기 도구(날짜 바꿔보기 등)는 주소 끝에 `#tools`를 붙여 열면 나와요. 패널 맨 아래에 앱 버전과 빌드 번호가 보여요.

## 업데이트 반영

- 인터넷이 켜진 상태로 앱을 열면 서버의 최신 화면을 바로 보여줘요. 2.5초 안에 응답이 없거나 오프라인이면 저장된 화면으로 열려요.
- 켜둔 채로 있던 앱은 다시 화면에 띄울 때 새 버전을 확인하고, 시작 화면에 있을 때 알아서 새로고침돼요. 터치 진행 중에는 새로고침하지 않아요.
- 이번 업데이트 전에 설치한 iPad: 앱을 완전히 닫았다가(앱 전환 화면에서 위로 밀기) 다시 열면 몇 초 뒤 새 버전으로 바뀌어요.
- 그래도 그대로면: 홈 화면 아이콘을 길게 눌러 삭제한 뒤, 사파리에서 주소를 다시 열고 "홈 화면에 추가"를 누르세요.

### 2026-10-12 · 버전 18
- 꾹 누르는 시간 2초 → 2.4초 (막대 하나당 0.8초)
- 막대 3개가 다 차면 손을 떼도 D-카운트(D-9→D-1, 0.6초)가 저절로 돌고 공개 화면으로 넘어감
- 누를 때 '톡', 막대가 찰 때마다 '쿵' (점점 무겁게), 카운트 드럼롤, 공개 차임

### 2026-10-12 · 버전 17
- 터치 방식: 세 번 터치 → 한 번 꾹 누르기(2초). 누르는 동안 01 HRD+ → 02 PAOLA-1 → 03 급여가 차례로 켜지고, 마지막 구간에서 D-카운트 후 공개
- 짧게 톡 치면 '꾹 눌러주세요' 안내, 중간에 떼면 처음으로 되감기
- 칸 아래 작은 글씨(첫/두/세 번째 터치) 삭제, 첫 화면 안내 '꾹 눌러주세요 / PRESS & HOLD'
- 흰 바 막대: 첫 화면의 반짝이는 연두색(빛나는 그라데이션 + 반짝임)
- 자동 초기화 60초 → 10초
- 빠르게 두 번 탭하거나 두 손가락으로 벌려도 화면이 확대되지 않게

### 2026-10-12 · 버전 16
- 터치 소리를 묵직하게: 밝은 '딸깍' 대신 낮은 '쿵' (세 번 모두 같은 낮은 음, 터치할수록 조금씩 더 무겁게)
- 꾹 누를 때 카운트: 한 옥타브 낮춘 음계 + 아래에 깔리는 낮은 드럼롤
- 공개 순간: 차임 아래에 낮은 착지음 추가

### 2026-10-12 · 버전 15
- 세 번째 단계 제목: '11월 1일 급여' → '급여'
- 효과음: 또렷한 딸깍(터치), 9→1로 한 음씩 올라가는 틱, 철금 차임, 탁·쿵·타닥 불꽃(좌우로 퍼짐)
- 꾹 누르는 첫 순간 카운트가 멈출 수 있던 문제 수정
- 앱이 새 버전을 바로 받아오도록 업데이트 방식 개선
