- 주소: https://kdqp304-arch.github.io/paola1-kiosk/
- 현재 버전: 30 (빌드 6cb6d105) · 2026-10-14
- iPad 사파리에서 주소를 열고 공유 → "홈 화면에 추가"를 누르면 아이콘이 생기고, 앱처럼 전체 화면으로 열려요.
- 처음 한 번 인터넷이 켜진 상태에서 열어두면, 그다음부터는 인터넷 없이도 열려요.
- 사용법: 화면을 꾹 눌러 위의 막대 3개를 채우면(2초) 손을 떼도 D-카운트(1초) 후 11.1 급여 화면이 나와요. 10초 뒤 처음 화면으로 돌아가요.
- 날짜: 10/23 전에는 D-9, 10/23부터는 실제 날짜를 따라가요.
- 미리보기 도구(날짜 바꿔보기 등)는 주소 끝에 `#tools`를 붙여 열면 나와요. 패널 맨 아래에 앱 버전과 빌드 번호가 보여요.
- 참여 기록: `#tools` 패널의 '참여 기록'에서 날짜별 완료 횟수를 보고, '보고서용 복사'로 7일 요약을 붙여넣을 수 있어요(이 기기에만 저장, 홈 화면 앱과 사파리는 따로).

## 업데이트 반영

- 인터넷이 켜진 상태로 앱을 열면 서버의 최신 화면을 바로 보여줘요. 2.5초 안에 응답이 없거나 오프라인이면 저장된 화면으로 열려요.
- 켜둔 채로 있던 앱은 다시 화면에 띄울 때 새 버전을 확인하고, 시작 화면에 있을 때 알아서 새로고침돼요. 터치 진행 중에는 새로고침하지 않아요.
- 이번 업데이트 전에 설치한 iPad: 앱을 완전히 닫았다가(앱 전환 화면에서 위로 밀기) 다시 열면 몇 초 뒤 새 버전으로 바뀌어요.
- 그래도 그대로면: 홈 화면 아이콘을 길게 눌러 삭제한 뒤, 사파리에서 주소를 다시 열고 "홈 화면에 추가"를 누르세요.
